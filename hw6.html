(a)¶

Assuming that we want to open 6 facilities, solve the p-median problem for the given set of customer and potential facility locations. Give an integer programming formulation of the problem, meaning that clearly state the decision variables, objective function and constraints. Solve the problem by calling Gurobi within a programming language and state the optimal objective function value, along with the optimal facility locations. At the end, you will find a piece of code for plotting the potential facility and customer locations, along with the connections you make. Using this piece of code or some other code you write, plot the optimal connections between the customer and facility locations.

Formulation¶

Let $i=1,\ldots,100$ index customers and $j=1,\ldots,30$ index facilities. We define $d_{ij}$ as their Euclidean distance in miles.

Let $y_j=1$ if facility $j$ is open and $x_{ij}=1$ if customer $i$ is assigned to facility $j$, 0 otherwise.

$$\begin{aligned} \min\quad &\sum_{i=1}^{100}\sum_{j=1}^{30} d_{ij} \cdot x_{ij}\\ \text{s.t.}\quad &\sum_{j=1}^{30}x_{ij}=1 &&\forall i \in \{1,...,100\},\\ &x_{ij}\le y_j &&\forall i \in \{1,....,100\},j \in \{1,....,30\},\\ &\sum_{j=1}^{30}y_j=6,\\ &x_{ij},y_j\in\{0,1\} &&\forall i,j. \end{aligned}$$

part = 'a'
model = gp.Model('pmedian_' + part, env=env)
model.Params.MIPGap = 0
x = model.addVars(noCusts, noFacs, vtype=GRB.BINARY, name='x')
y = model.addVars(noFacs, vtype=GRB.BINARY, name='y')
model.setObjective(gp.quicksum(distances[i, j] * x[i, j]
                   for i in range(noCusts) for j in range(noFacs)),
                   GRB.MINIMIZE)
model.addConstrs((gp.quicksum(x[i, j] for j in range(noFacs)) == 1
                 for i in range(noCusts)), name='assign_once')
model.addConstrs((x[i, j] <= y[j]
                 for i in range(noCusts) for j in range(noFacs)),
                name='assign_to_open')
model.addConstr(gp.quicksum(y[j] for j in range(noFacs)) == p)
model.optimize()
assert model.Status == GRB.OPTIMAL

openFacs = [j for j in range(noFacs) if y[j].X > 0.5]
assgns = [next(j for j in range(noFacs) if x[i, j].X > 0.5)
          for i in range(noCusts)]

print(f'Optimal objective: {model.ObjVal:.9f} miles')
print(f'Best bound: {model.ObjBound:.9f}; MIP gap: {model.MIPGap:.1%}')

(b)¶

In addition to the model specification in Part a, we want to impose the additional requirement that if we open a certain facility, then we must have another facility open within 3 miles of the opened facility. Give an integer programming formulation of the problem, solve the problem by calling Gurobi within a programming language, state the optimal objective function value and plot the optimal solution.

Formulation¶

We use the objective and all constraints from part (a), and add the following constraint.

Let $N_j$ be the set of other facilities within 3 miles of facility $j$.

Thus, $$y_j\le\sum_{k\in N_j}y_k\qquad\forall j \in \{1,...,30\}$$

(c)¶

Go back to the model in Part a. In addition to the model specification in Part a, we want to impose the additional requirement that if two customer locations are within 0.6 miles of each other, then we cannot assign them to the same facility location. Give an integer programming formulation of the problem, solve the problem by calling Gurobi within a programming language, state the optimal objective function value and plot the optimal solution.

Formulation¶

We use the model from part (a) without the extra constraints from part (b).

For every pair of customers $i$ and $h$ within 0.6 miles of each other, we add this constraint for every facility $j$:

$$x_{ij} + x_{hj} \le 1$$

This means the two customers cannot both be assigned to the same facility.

y = model.addVars(noFacs, vtype=GRB.BINARY, name='y')

                   for i in range(noCusts) for j in range(noFacs)),

                 for i in range(noCusts)), name='assign_once')
model.addConstrs((x[i, j] <= y[j]
                 for i in range(noCusts) for j in range(noFacs)),
                name='assign_to_open')
model.addConstr(gp.quicksum(y[j] for j in range(noFacs)) == p)
# Each unordered customer pair appears exactly once.
customer_hundredths = np.rint(np.array(customers) * 100).astype(int)
close_pairs = [(i, h) for i in range(noCusts)
               for h in range(i + 1, noCusts)
               if np.sum((customer_hundredths[i] -
                          customer_hundredths[h]) ** 2) <= 60 ** 2]
model.addConstrs((x[i, j] + x[h, j] <= 1
                 for i, h in close_pairs for j in range(noFacs)),
                name='separate_customers')
model.optimize()
